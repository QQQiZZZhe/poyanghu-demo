# 评审视频：脚本、画面与分镜

这条片子是给作品评审看的，不是预告片，所以它按评委想知道的顺序走：先讲清楚这个作品为谁而做、想说什么，再用真实操作把玩法演一遍，最后把技术上真正花过功夫的地方拆开。整条片子由工程里的演示程序 `scenes/demo.tscn` 自动跑出来，画面全部是游戏本体在 1280×720 下实机渲染的，没有一张后期拼贴的假界面。

演示程序不是录屏脚本，它和游戏共用同一套场景与 UI。它只做三件事：按时间轴调用玩家本来就会点的那些入口、在画面上叠一条解说字幕、在段落之间插章节卡。玩法逻辑、数值和动画一行都没有为录像改过，所以片子里看到的结算数字，就是这一局真实的数字。

## 二、旁白逐字稿

上面表格最后一列就是全文，约 680 字。按每分钟 200 字配，落在 3 分 25 秒左右；画面是 3 分 12 秒，差的这十几秒靠片头片尾各留两三秒黑场补平，也可以把 1:25 那段结算小票的停留再拉长一点。如果配音偏慢，优先砍 0:19 和 1:27 两段的解释性半句，不要动 1:12 那句水位设计——那是这个作品和普通环保答题游戏的分水岭。

## 三、演示程序怎么用

场景是 `res://scenes/demo.tscn`，导演脚本是 `scripts/demo_director.gd`。它把游戏主场景实例化在下面，自己只做时间轴，所以打开它跑起来就是完整游戏，只是有人在替你点按钮。

录制整条片子：

```
Godot_v4.7.2-stable_win64_console.exe --path <工程> res://scenes/demo.tscn \
  --write-movie <输出目录>/demo.avi --fixed-fps 30
```

写 AVI 比写 PNG 序列快一个量级。同一台机器上，PNG 序列在这轮实测只有每秒三到十帧的落盘速度，四分钟的片子要录二十分钟以上；AVI 一次跑完六百帧只用了二十三秒，整片四分钟大约五分钟就能录完，代价是中间文件接近一 GB，转成 mp4 之后可以删掉。

调试时用 `--fast` 把解说等待压到 8%，整条片子三十多秒跑完，用来验证流程不崩；`--skip-intro` 从开局直接开始，专看局内那几分钟。两个开关都不影响正式录制。

导演脚本里每个段落对应一个函数：`_menu_part`、`_knowledge_part`、`_start_part`、`_board_part`、`_first_turn_part`、`_more_turns_part`、`_tech_part`、`_ending_part`、`_outro_part`。要改某一段的台词或停留时间，只改那个函数里的 `_say(...)` 第二个参数，不用碰别的段落。字幕条的上下位置由 `_sub_at_top()` 统一切换：菜单和图鉴放屏幕下缘避开标题，局内放上缘避开手牌。

## 四、录制与后期

AVI 里自带一条 48kHz 立体声 PCM 音轨——Godot 的 movie maker 把游戏当时真的在放的声音一起写进去了，转 mp4 时 ffmpeg 默认把它压成 AAC，所以成片里的 BGM、发牌声和结算那声「叮」都在，实测整体平均 -24.5 dB、峰值 -2.4 dB，不是静音。缺的只是旁白人声。

```
ffmpeg -i demo.avi -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart demo_review.mp4
```

要加旁白的话，按分镜录一条 3 分 25 秒的干声，压在 -18 LUFS 左右，再和这条原声轨混一次就行；卡牌落桌和结算的拍点已经在原声里，不需要另配音效。录的时候窗口保持 1280×720、不要最小化，鼠标移出窗口——菜单与图鉴段的悬停仍然读真实指针，倾斜特写那段导演已经用 `flying` 标记把控制权接过去了。

## 五、已经证过的与没证的

整片用 AVI 录完 5780 帧，转成 192.7 秒的 mp4 放在 `outputs/review-video/demo_review.mp4`。逐段抽帧核对过片头卡、主菜单、知识卡图鉴、局内第一回合、结算小票、牌库全屏、大卡倾斜特写、结尾短片和收尾卡：字幕条在菜单与图鉴落在屏幕下缘、在局内落在上缘，两处都没有压住标题或手牌；结尾那段两分钟短片在 `--write-movie` 下正常解码，抽 172 秒能看到短片自己的「鄱阳湖 Poyang Lake」标题卡，184 秒是「白鹤归来，四野无食」那一段。音轨用 volumedetect 量过，AVI 与转出来的 mp4 都带声。

倾斜特写这段返工过一次。第一版把牌打到待执行区再倾斜，录出来发现那张牌落在右上角的小格子里，还被解说条压住，等于没演；第二版改成先打开牌库、再点开一张卡详情，用详情页左侧那张放大 1.8 倍的牌做载体，抽 155 秒能看到「封洲禁牧」的明显透视变形，边缘和投影都在动。

字幕条也补过一次：原来条高写死 52 像素，一条 44 字的台词折行后第二行跑到条外、压住牌库卡面，改成按 Label 的实际行数撑高之后，两行都包在深色条里。

没证的有两件。旁白没录，成片只有游戏原声；连续回合那段的解说只有开头一句，中段是靠画面自己走的，如果配音要压得更紧，得在 `_more_turns_part` 里再补两三句 `_say`，每补一句成片会长四到五秒。
