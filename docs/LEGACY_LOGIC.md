# 老版逻辑与新版美术

以分支原有的 `8b0807f` 为逻辑基准。`scripts/achievements.gd`、`scripts/talents.gd` 和 `scenes/main.tscn` 与该提交一致；`scripts/game_state.gd` 后续仅合入队友 `af8e159` 的 39 项卡牌价格调整，其余内容与该提交一致。回合、事件、危机、难度、预算、行动槽位、种群计算、天赋、成就和存档格式沿用老版。新版美术由 `pixel_wetland.gd` 读取游戏状态，不改写玩法数据。

主菜单与对局使用实际的正交 Camera3D，方位角和俯角均为 45 度。菜单用 1.2 秒拉远，进入对局用 0.8 秒推进，沿用 Sine / Ease Out。按后续美术要求，菜单视野倍数为 1.3，对局为 0.9（比原对局再推进约 11%）；房屋、植物、鸟与水面特效随摄像机同步缩放。

苦力怕使用原始素材，位于右上方外围草地。菜单能看见完整脸部，进入对局后整个贴图自然处于镜头之外；回菜单时随镜头拉远移入画面。每次进入主菜单以 10% 概率重新决定是否显示；开始或继续对局保留该次结果。树木与房屋避开彩蛋区域。装饰随机数独立于游戏随机数。

场景更新沿用结算期间冻结、结算结束统一同步的时机；村落不再提前抢跑。鸟类按每 10 点种群一个、每种最多 10 个显示；植物按每 7 点一个显示；鱼按每 12 点资源一个显示；围垦强度按 0–100 对应 0–7 栋房屋，社区信任决定亮灯比例。额外岸边地块保留芦苇美术。暂停时冻结场景动画，恢复后继续。

鸟类仍有待机、啄食、行走、植被越好越容易飞向树木停歇等生态表现，使用新的动作图集显示，始终脚在下，仅水平翻转。

Windows / Godot 4.7.2 图形回归测试 `tests/visual_smoke.gd` 验证菜单镜头、入场推进、彩蛋两种概率结果与开局保留、地面投影、动画帧、村落上限与结算冻结、暂停、出牌、结算、下一季、存读档和窗口缩放。结果：`VISUAL_SMOKE: PASS (0 failures)`。
