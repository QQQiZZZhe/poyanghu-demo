# 天赋树与灵感（2026-10-03）

主菜单的「天赋树 · 灵感研修」位于开始与设置之间。保留原有种子驱动的开局随机0～3项天赋，在此基础上恢复并重新设计永久成长。

胜利结果发放灵感，包含提前胜利，不以分数评级或16回合限制奖励：简单1、普通2、困难3。噩梦胜利不增加灵感，而是永久授予全部18项天赋满级，并解除所有分配上限。失败与中途退出不发奖。本次只调整奖励资格，未添加新的提前胜利触发条件；现有自然通关流程仍为16回合。

每局使用独立随机生成的128位标识，存入单局存档和奖励领取记录。重复打开报告、重启后再次打开同一份结算不会重复发放；同种子的另一局仍可领奖。奖励落盘失败会回滚内存并在报告中提示。

## 分配结构

免费起点「守护初心」通向水文、生态、共治三个方向，其中最多投入两级，即三选二。第二层每个方向的两个后继各至多二级，同组总等级至多三级。第三层交叉研修总等级至多三级。第四层三个专精只可选择一个。分配上限计算节点等级，灵感价格按每次升一级计费；前置需要至少一级。

普通分配填满所有层的上限共需17灵感。交叉前置让不同方向有组合价值，并通过任一前置保留单路线进入经济、运营分支的选择。参考集成战略的分层、多后继思路，具体节点与限制为本游戏设计。界面实线表示全部前置，虚线表示任一前置；选中节点显示完整效果、前置和同组已用等级。

免费重置返还已投入的全部灵感，支持重新选择路径。噩梦已满树时停用重置，防止把免费满级奖励兑换为灵感。

## 削弱幅度与兼容

对照旧30项线性树全部解锁，永久拨款从+10万削减至全树最多+3万（−70%），卡牌折扣从20%削减至2%（−90%），结转上限从+20万削减至+6万（−70%），开局指标由旧「全指标+4、单项+6」的合计+10，降至全树每项+3～4（−60%～70%）。移除永久额外抽牌、首回合行动位、利息以及全指标统一加成；运营成本最多−2万、危机概率最多−2个百分点。普通分配受方向和层级上限约束，无法同时取得这些全树最大值。

永久研修只在开局捕获一次。调整或重置配置只影响之后的新局；当前局的节点等级和噩梦资格随单局存档恢复，避免读档途中改变加成或重掷随机天赋。开局弹窗显示永久加成汇总，左上角永久研修提示提供全部节点详情。

`talents.json`沿用旧文件，版本升级为2，保留旧`points`与`unlocked`字段。旧点数可能来自高评分失败局，因此不会转换为只允许胜利获取的灵感，旧线性加成也不会再次计入。缺少新字段的旧单局按无永久研修恢复，并生成稳定的旧存档结算标识。
