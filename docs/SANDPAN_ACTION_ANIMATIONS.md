# 沙盘行动反馈（2026-10-02）

新版保留真实 45° 正交 Camera3D，采用现有像素素材呈现旧版生态反馈。

| 行动或变化 | 沙盘表现 |
|---|---|
| 补水、蓄水、控水、水位自然涨落、干旱/洪水 | 湖岸连续扩张或退缩；涨水覆盖原岸滩，退水露出沙边与湖床 |
| 水质治理或恶化 | 水色连续变清或浑浊；治理行动有水面波纹反馈 |
| 人工浮岛 | 沿用旧规则生成 4 座浮岛，逐座从水面浮起并产生涟漪 |
| 底泥清淤疏浚 | 沿用旧规则清除浮岛，播放缩小淡出动画 |
| 植被补种、栖息地恢复 | 对应植物按原种群/7的显示阈值逐渐生长；退化时收缩 |
| 鱼类恢复、候鸟种群增减 | 鱼群、鸟群按原数量阈值渐入或渐出，鸟类继续原有移动和逐帧动作 |
| 社区用地变化 | 保留旧版最多7栋房屋的建造、拆除与恢复芦苇效果 |
| 巡逻、共管、智慧巡护、监测科研 | 巡护船或扫描圈作为出牌反馈 |

`main.gd` 在每张成功执行的手牌（含紧急调度）之后保存只读沙盘快照。算分的逐张弹分阶段回放该快照，之后播放延迟到期、协同、自然演化和危机的最终状态。延迟牌不会在预告阶段提前改变水域；浮岛实体按旧版行动时机直接建造，净化指标按原延迟规则生效。

`pixel_wetland.gd` 只插值显示状态，不重新执行卡牌、不改 GameState、不消耗全局游戏随机数。`game_state.gd` 保持不变，存档字段与评分规则保持一致。动画支持暂停、300%结算速度和减少动态效果。

`lake-shore-distance.png` 是原地形水域分类生成的像素距离数据；`wetland_ground.gdshader` 用其移动湖岸。范围限制在湖盆，保留延伸河道以及河湖交界的蓝色通道。该视觉映射不模拟真实湖盆高程。生成器：`python tools/generate_lake_distance_field.py`（Pillow、NumPy）。
