# 鄱阳湖地形底图

当前地形：`assets/art/poyang-terrain-base.png`，1024×1024、北向上的源底图，只有深水、浅水、岸滩和陆地四种纯色。游戏将底图铺在独立 3D 场景的 `PlaneMesh` 上，用方位角 45°、俯角 45° 的正交 `Camera3D` 拍摄。房屋、植物和鸟类的位置由这台摄像机投影到屏幕，贴图保持直立；鸟类按投影后的移动方向左右翻转，足部始终朝下。地图的湖形和河道由经纬度数据直接绘制。

## 地理范围与水系

- 北部保留鄱阳湖狭长水道，在湖口连接长江；长江在画面上方沿实际中心线经过。
- 赣江从西南方向进入湖区，保留公开地图中的主流、南支与中支的位置和分汊关系。
- 湖形来自 PML 发布的 ESA CCI 150 米最大水域轮廓矢量化数据 `GLWD00000078`。它用于表达丰水期湖形，不是某次洪水的测绘边界，也没有对应单一观测日期。原始记录面积为 2622.55 平方千米。
- 河道中心线来自 OpenStreetMap。河宽、岸滩和浅水带是像素游戏表现；浅水/深水配色不是实测水深。
- 经纬度范围为东经 115.525241050–117.094758950 度、北纬 28.52–29.89 度；使用中心纬度修正东西距离，保持东西与南北距离同比例。
- 真实湖形较狭长，因此优先保留地理比例，未将湖面人为扩大至方形画面的 50–60%。

## 来源与许可

- 湖形：[PML lake-polygons-PML](https://github.com/pmlrsg/lake-polygons-PML)，[原始坐标](https://raw.githubusercontent.com/pmlrsg/lake-polygons-PML/master/CLMS4k/GLWD00000078.txt)。相关湖形数据及其派生底图按 GPL-3.0 发布；许可证见 `geography/LICENSE-PML.txt`。
- 河道：© OpenStreetMap contributors，原始数据库及提供的河道坐标依照 [ODbL](https://www.openstreetmap.org/copyright)。长江主关系 `9392345`；赣江分支包含 `49002749`、`49002751`、`49578627`、`49578644` 等。
- 丰枯水季节变化参考：[NASA Poyang Lake Extremes](https://science.nasa.gov/earth/earth-observatory/poyang-lake-extremes-146987/)。未将其 2020 年极端洪水水域作为本图的单日边界。
- 可复现的坐标和来源属性保存在 `geography/poyang-hydrography.geojson`。

## 重新导出

安装 Pillow 后，在项目根目录运行：

```sh
python3 tools/build_poyang_terrain.py
```

地图先按 512×512 逻辑像素栅格绘制，再以最近邻放大为 1024×1024，不使用抗锯齿、渐变、阴影或纹理。陆地 `#829666`，岸滩 `#D8C68D`，浅水 `#63AFCB`，深水 `#176783`。

原始创意要求是“直接俯视、16 位像素风、1024×1024、仅地形、湖面与河流、无植物建筑动物文字”。此前的内置 image_gen 示意图未采用。最终按用户补充的真实鄱阳湖轮廓及长江、赣江位置要求，直接使用公开地理坐标生成地形。

## 验证范围

已检查图像尺寸、四种精确颜色、北向上坐标换算、河道坐标抽样及重复导出结果。对局中的地图以 1.58 倍默认缩放显示，窗口会裁切部分外围陆地和南北两端；原始 PNG 保留完整地理范围。像素岸线不使用 UV 水波位移。鱼群、船只、浮岛、植物与房屋在独立图层绘制，位置按地形颜色或固定地块选择，不写入地形底图。

旧版 3D 沙盘中的视觉规则已移到 2D：鸟在水域停留、啄食、行走，并在植被较好时更可能飞向池杉停歇；五种鸟各有自行绘制的站立、行走、啄食、飞行及栖息帧，飞行和行走方向跟随目的地方向；各植物种群按原先约每 7 点一个可见个体的比例出现。村落地块在真实湖岸附近的陆地像素上选址，并交错分布在湖的两侧；数量仍按原围垦强度比例增减，改变时播放建造或退去动画，空地显示芦苇。房屋仍使用仓库原有四张素材并随社区信任度调整亮度。浮岛和外围树木为自行绘制的像素素材，外围树木避开房屋与苦力怕的空地；苦力怕使用原素材，沿用每次进入主菜单以 10% 概率出现的条件。

已在 macOS 上用 Godot 4.7.2 运行当前版本，隔离试玩测试输出 `VISUAL_SMOKE: PASS (0 failures)`，并目视检查了对局中的地图、房屋、植被与鸟类。

## Windows 主菜单景观更新

当前地形通过真实的 45 度正交 Camera3D 显示。菜单视野系数为 1.3，对局为 0.9，阴影在屏幕宽度 40% 处完全消失。苦力怕位于右上方外围草地，主菜单内能看见完整贴图，对局推进后整个贴图位于屏幕外，回菜单时随镜头拉远进入画面。

`build_poyang_terrain.py` 同时生成 `scripts/wetland_rivers.gd`，保留上述 OpenStreetMap 长江、赣江主河道中心线。运行时以地面三角网格绘制河岸、浅水和河芯；在原底图的边界沿河道末端方向延伸至镜头外。边界之外属于游戏布景延伸，不代表实测地理。小船按中心线弧长移动，船尾带水纹；暂停和减少动态效果设置仍然生效。

河岸层在与原底图水面重叠时读取底图对应的浅水或深水蓝色，不再把沙色岸线画在水道交汇处。赣江、鄱阳湖与长江之间的水面保持连通，外侧陆地仍显示沙色岸滩。

空地增加原创代码绘制的像素草丛、野花、灌木、石头和松树，并搭配已有的阔叶树素材。装饰使用独立固定种子，不消耗玩法随机数，不改变植物种群、资源或回合计算；避开河流、房屋及苦力怕半径 0.15 的空地。
